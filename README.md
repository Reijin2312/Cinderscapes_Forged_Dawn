# Cinderscapes: Forged Dawn

An unofficial native NeoForge port of [Cinderscapes](https://github.com/TerraformersMC/Cinderscapes) for Minecraft 1.21.1.

Cinderscapes expands the Nether with four detailed biomes and their associated blocks, plants, sounds, particles, recipes, and world-generation features:

- Ashy Shoals
- Blackstone Shales
- Luminous Grove
- Quartz Cavern

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1 or newer
- Cloth Config 15.0.140 or newer

Biolith is bundled in the release JAR and does not need to be installed separately.

## Support

Report port-specific bugs through this repository's issue tracker and include `latest.log`, the exact mod version, and a complete mod list.
